# 客服工单趋势分析 (0111)

## 项目简介

本项目使用 Java 对 50 条客服工单数据（2024-06-01 ~ 2024-06-11）进行自动化趋势分析，识别异常信号，生成可视化图表和 HTML 报告，帮助客服主管快速了解工单动态。

## 技术栈

- **语言**: Java 21
- **构建工具**: Maven
- **依赖库**: Jackson (JSON解析) + XChart (图表生成)
- **输出格式**: 控制台报告 + PNG图表 + HTML可视化报告

## 分析维度设计

| 维度 | 说明 | 对主管决策的价值 |
|------|------|-----------------|
| **时间趋势** | 每日工单量变化 | 识别业务高峰期，合理调配人力 |
| **分类分布** | 问题类型占比 | 定位高频问题，推动产品/流程改进 |
| **优先级分布** | 高/中/低优先级占比 | 确定资源投入优先级 |
| **渠道分布** | 在线/电话/邮件来源 | 优化渠道服务策略 |
| **处理时长** | 各类别平均处理时间 | 发现效率瓶颈 |
| **满意度** | 各类别满意度评分 | 识别体验最差环节 |
| **解决状态** | 已解决 vs 未解决 | 监控工单积压风险 |

## 关键发现

### 异常信号

1. **支付问题集中爆发** — 支付问题共 15 单（30%），为所有分类中最高，可能存在系统性支付故障
2. **未解决工单积压** — 6 单未解决（12%），多为高优先级，涉及退款退货和支付问题
3. **低满意度集中** — 满意度≤2 的工单占 52%，集中在支付问题和退款退货
4. **超长处理时长** — 处理时长≥48h 的工单有 5 单，最长达 120 小时
5. **退款退货反复出现** — 贯穿整个周期，涉及运费争议、退款延迟、审核慢等子问题
6. **后半段高优先级增多** — 6/6 之后高优先级工单占比上升，问题严重程度加剧

### 关键数据

- 工单总数：50 单
- 平均处理时长：约 23 小时
- 平均满意度：约 2.44 / 5
- 解决率：88%

## 运行方式

```bash
# 1. 编译项目
mvn clean compile

# 2. 运行分析
mvn exec:java -Dexec.mainClass="com.partner.TicketAnalyzer"
```

运行后输出：
- 控制台：完整文字分析报告
- `output/` 目录：9 张 PNG 图表
- `output/report.html`：完整 HTML 可视化报告（用浏览器打开即可查看）

## 输出文件说明

| 文件 | 说明 |
|------|------|

| `output/unresolved_category.png` | 未解决工单分类 |
| `output/period_priority.png` | 前后半段优先级对比 |
